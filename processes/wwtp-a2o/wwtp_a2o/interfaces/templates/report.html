Understand the process

Influent → Anaerobic (A1, A2) → Anoxic (A3, A4) → Aerobic (O1, O2, O3) → Clarifier (C1) → Effluent

Internal recycle: O3 → A3. Return sludge: C1 → A1. Waste sludge leaves C1. These are seven calculation tanks in three functional zones. The BFD groups these zones; the PFD shows each calculation tank.

Open the project in the ChemE-as-Code viewer for the current BFD, PFD and Stream table. The values in this report belong to the saved run identified above.
